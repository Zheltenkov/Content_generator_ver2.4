Backlog Work Plan

Проект учит превращать неопределенную бизнес-инициативу в управляемый backlog с проверяемыми критериями готовности.

Практическая цель

  1. Собрать входные требования и ограничения продукта.
  2. Декомпозировать инициативы на user stories.
  3. Задать acceptance criteria и приоритеты.
  4. Подготовить план refinement-сессии.

Ожидаемый результат

Markdown-таблица backlog, board screenshot и список вопросов к stakeholder review.
